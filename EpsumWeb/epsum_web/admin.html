API Reference

REST API endpoints for integrating your CMS with the EpsumThings website. Base URL: https://api.epsumthings.com/v1

📄 Blog Endpoints

GET /blogs List all blogs
GET /blogs/:slug Get single blog
POST /blogs Create blog
PUT /blogs/:id Update blog
DEL /blogs/:id Delete blog

📊 Case Study Endpoints

GET /case-studies List all
GET /case-studies/:slug Get single
POST /case-studies Create
PUT /case-studies/:id Update
DEL /case-studies/:id Delete

📩 Communications Endpoints

POST /contact Submit contact form
POST /demo-request Submit demo request
GET /messages List all messages
PUT /messages/:id/read Mark as read
POST /upload Upload image (multipart)

Full API documentation with request/response schemas is available in the api-server.js file.
